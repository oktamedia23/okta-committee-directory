# OKTA 통상위원회 회원 디렉토리

OKTA 세계한인경제무역협회 회원 5,095명을 15개 통상위원회 분과로 분류한 디렉토리입니다.

## 주요 기능
- 15개 통상위원회 분과 카드 → 클릭 시 해당 분과 회원 목록
- 제23대 상임이사 직위 표시 (이사장단/상임집행부/명예회장/감사/지회장)
- 권역/국가/지회/직위 필터 + 통합 검색
